# UI Label Rename (Campaign → Event, Agent → Unit) — Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename all user-visible "Campaign(s)" labels to "Event(s)" and "Agent(s)" labels to "Unit(s)" across all 3 frontend apps.

**Architecture:** UI-only text replacement. No database, code variable, file name, or route changes. Only JSX string literals, nav labels, page titles, card titles, table headers, button text, dialog titles, and descriptions are modified.

**Tech Stack:** React 18, TSX files in admin-portal, agent-portal, public-pages
